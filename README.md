# Kunj Restaurant — React + Vite + Tailwind UI Demo

## Run
```bash
npm install
npm run dev
```

## Notes
- Frontend-only demo. No Django, database, authentication, payments, or real order processing.
- Menu data is isolated in `src/main.jsx` for this single-file demo and can be moved directly to `src/data/menuData.js` when desired.
- No real phone number or street address is invented.
- Sample testimonials are explicitly labeled as demo content.
- Images use Unsplash URLs as remote demo assets.
